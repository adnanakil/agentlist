Add Credential

Some agents need your own API keys (e.g. INSTACART_API_KEY). Store them here and they'll be securely injected when you invoke those agents. If a credential with the same name already exists, it will be updated.

How consumer credentials work

  • Credentials are encrypted with AES-256 (Fernet) before storage
  • When you invoke an agent, your credentials are decrypted and injected as environment variables
  • Agents receive them as CONSUMER_CRED_{NAME} (e.g. CONSUMER_CRED_INSTACART_API_KEY)
  • Values are never displayed after saving — only the name is shown
  • Check an agent's listing to see which consumer credentials it requires
