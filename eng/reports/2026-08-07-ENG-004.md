## Changes

### 1. Message icon (↗ → speech-bubble SVG)

Hero CTA, sticky mobile bar, and closing-section CTA all now carry this SVG instead of `↗`:
```html
<svg width="16" height="16" viewBox="0 0 24 24" fill="currentColor" aria-hidden="true">
  <path d="M20 2H4a2 2 0 00-2 2v18l4-4h14a2 2 0 002-2V4a2 2 0 00-2-2z"/>
</svg>
```
This is a Material Design filled chat-bubble icon. nav_cta left as `↗` (it's a navigation link, not an SMS action).

### 2. Microcopy (mobile only)

Added below the hero CTA `<a>`:
```html
<p class="cta-mob-hint">Opens your Messages app · one text to start.</p>
```
CSS: `display:none` base, `display:block` in `@media (max-width:820px)`.

### 3. SMS preview bubble (mobile only, hero only)

Added above the hero CTA `<a>`:
```html
<div class="cta-preview">
  <span class="sms-bubble">"Hi HAL — new baby here 👶"</span>
  <p class="sms-preview-hint">Tap to send · HAL replies instantly</p>
</div>
```
CSS: `display:none` base, `display:block` in `@media (max-width:820px)`. Shows the exact pre-filled text the visitor will send, removing the "surprise" when Messages opens.


```bash

             services/hal-orchestrator/hal_orchestrator/tools/baby.py \

```

**Order matters**: deploy before stash pop; the pop brings the baby-tracker changes back into the working tree for Adnan's next step.
