## What was built

**`services/hal-orchestrator/hal_orchestrator/routes/landing.py`**:
- `_qr_svg(data: str) -> str` — lazily imports qrcode, builds an inline SVG via run-length-encoded `<rect>` elements from the QR module matrix. Returns `""` on ImportError (fail-open).
- In `render_landing()`: computes `qr_attr_code = code[:30]+"qr"` (or `"qr"` if no code), generates QR SVG encoding `https://www.texthal.com/go/{qr_attr_code}`, builds `qr_block` div with `data-qr-url` for inspection.
- `qr_block` injected into `hero_cta` before closing `</div>`, inside the `number`-truthy branch.
- CSS: `.qr-desk-block { display:none; }` + `html.desk .qr-desk-block { display:flex … }` using the existing JS `.desk` class gate from ENG-010.

**`services/hal-orchestrator/pyproject.toml`**:

**`services/hal-orchestrator/tests_onboarding_parent.py`**:
